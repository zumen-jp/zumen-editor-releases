# zumen-editor

Windows 11 x64 用の図面エディターです。図面を手元で開き、編集や照合ができます。

[リリース一覧](https://github.com/zumen-jp/zumen-editor-releases/releases) から MSI をダウンロードして開きます。インストール後はスタートメニューの「zumen-editor」から起動できます。先行版は未署名のため、Windows が発行元を確認できない旨を表示する場合があります。同じリリースの SHA-256 ファイルでダウンロードした MSI を照合できます。
